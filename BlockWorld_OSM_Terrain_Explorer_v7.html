Map editor
Import any standard .osm or .xml export. OSM contains coordinates and features, not aerial imagery.

Map boundary and crop

Crop hides geometry outside the rectangle, including roads. It does not delete original OSM features.

Layers and view

Real elevation — GeoTIFF

Import one or more unzipped .tif/.tiff DEM tiles. Their map coordinates are used to align automatically with OSM. Requires internet for GeoTIFF reader when first opened.
No elevation files imported.
GeoTIFF tiles are stored in RAM during this session. Re-import the .tif files after reopening; project JSON does not embed TIFFs. Supports georeferenced EPSG:7854, EPSG:28354 and EPSG:4326 tiles.

Terrain realism and inspection

Display modes change only the appearance, not the source elevation. Vertical exaggeration is visualization only.
Tap Measure slope, then tap two points in Map or Orbit view.
Orbit controls: one finger drag = rotate; two fingers drag = pan (and pinch = zoom). Mouse: left drag rotates; right/Shift-drag pans; wheel zooms. Double-tap terrain to center orbit there.

Rotated construction grids

Selected grid

Auto-detection groups dominant road angles by geographic zone. Angles are suggestions; refine them manually.

Player starting position

Tap a road or any location in Map view to place the player. The orange marker shows the selected position. Switch to Walk to start there. The location is saved with the project.

Save / share / reopen

JSON retains imported geometry, crop and grids. HTML embeds your project directly in this viewer. iPhone's Share Sheet appears when supported; otherwise the file is downloaded.

About geometry

OSM roads are centerlines with estimated widths. Property boundaries aren't synthesized. Single composited terrain surface: roads override paths, water and grass.
