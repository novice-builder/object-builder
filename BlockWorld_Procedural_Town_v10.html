GeoTIFF tiles are stored in RAM during this session. Re-import the .tif files after reopening; project JSON does not embed TIFFs. Supports georeferenced EPSG:7854, EPSG:28354 and EPSG:4326 tiles.

Terrain shape and detail

Aerial: no file · Canopy: no file · Estimated trees from OSM park / woodland areas.
RGB and canopy raster tiles must be georeferenced EPSG:7854, 28354 or 4326. Canopy is height above ground, not elevation. This experimental importer is intended for manageable raster tiles, not multi-gigabyte LAS/LAZ archives.

Player starting position

Tap a road or any location in Map view to place the player. The orange marker shows the selected position. Switch to Walk to start there. The location is saved with the project.

Save / share / reopen

JSON retains imported geometry, crop and grids. HTML embeds your project directly in this viewer. iPhone's Share Sheet appears when supported; otherwise the file is downloaded.

About geometry

OSM roads are centerlines with estimated widths. Property boundaries aren't synthesized. Single composited terrain surface: roads override paths, water and grass.
