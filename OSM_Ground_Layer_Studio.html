1 · Import OSM

Open uncompressed OSM XML containing nodes, ways and optionally relations. Processing stays on your computer.

Choose an OSM map to begin.

2 · Detected layers and materials

Tick to show/hide. Drag the ☰ handle to reorder; lower in this list draws on top. Choose a colour or an optional image texture per layer. Layers without matching map features show 0.

Line widths are in metres; if OSM supplies a numerical width tag it is used only when the “Use tagged widths” option is enabled.

3 · Preview and movement

Drag to pan in Top-down. In Orbit, drag to rotate and tilt. In Walk, use ↑/↓ to move and ←/→ to turn. Wheel to zoom in the top and orbit views. This is a projected flat-ground inspector, not a full 3D terrain engine.

4 · Boundary and export

Features are clipped to the file's <bounds> rectangle, or node extent if no valid bounds exist. Geometry cannot expand the map boundary. Administrative relations are treated as features, not as the clip boundary.

The JPEG is a flat overhead image suitable for map cards. SVG preserves vector paths and embedded texture images. SVG layers are in priority order; overlapping ground features are composited, not physically cut into a non-overlapping mesh.
