## Standard controller input milestone

Standard-mapping Gamepad API support now uses the existing movement/look/action callbacks: left/right sticks, radial deadzones, A/B, X Build, Y Interact, right-bumper rotation, stick-click Run, View map and Menu. D-pad focus navigation includes model thumbnails, edit buttons and map destination selection; A confirms travel. Connections/interruptions require neutral input before accepting new commands. Held buttons emit one edge action; disconnect/API denial immediately clears controller motion while touch/keyboard remain. The menu includes controller mapping help. Native Space/Enter button behaviour is preserved, and full overlays now poll input without continually rendering their hidden 3D background.

The full suite has 147 passing deterministic tests. The gamepad pass has 26 browser checks using injected standard snapshots, including movement/camera, map pan/zoom/travel in the same save, D-pad catalogue, placement/rotation, event/poll disconnect, denied API and touch fallback. This is **not** a physical Xbox/Bluetooth, Lenovo, iPhone or Safari test. Browser support/secure-context requirements vary; unrecognised mappings are ignored safely. Real pairing, button labels, latency and ergonomics remain unverified.
