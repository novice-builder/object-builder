# Player vehicle fleet

County now offers three immediately available vehicles: original buggy, cargo-bed ranch runabout and original low-poly bicycle. Live map destinations find each vehicle. All use the existing joystick steering/forward/reverse and Use entry/exit. Bicycle uses a narrower/shorter oriented footprint and a 4.5 m/s speed; runabout 5.2 m/s; buggy retains 6 m/s. Each has separate persistent parking, backed up with the world. Four traffic vehicles remain simulation-only.

World collision, parked vehicles, horses, water and traffic block driving. Vehicle positions are checked before changing an active saved world. Default extra vehicles can move to a clear nearby position around existing player constructions; blocks are never relocated. Save while driving records a checked on-foot arrival beside the car/bicycle; reload leaves the vehicle parked. A blocked exit retains the driver. Map/Home recover safely. Earlier templates retain their original one-vehicle population and saved buggy field; optional fleet data is validated and restricted to known county vehicles.

Executed: eight focused deterministic cases passed, covering both new vehicle cases plus companion/riding regressions. Four touch-browser scenarios passed: utility/bicycle map entry, real joystick driving, camera, save while driving/reload and exit; original county driving; companion controls; riding. Strict TypeScript/build/preservation passed. Controls are intentionally shared and simple; pedalling/drivetrain simulation, suspension, physical slopes and physical-device performance qualification remain future work.
