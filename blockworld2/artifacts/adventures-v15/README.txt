SAVE SAFETY: Default port 8015 keeps older :8000/:8013/:8014 browser storage separate. Bring an older world across by exporting its .bw2 backup and using Menu > Import backup here. Import creates an independent record; retain the original export and browser/address. Changing browser/address/port changes storage. Browser-private storage is not a permanent backup. `--port 8016` selects another local address.

INN COMMON ROOMS: Fresh full-sized inns now have two dining tables with facing chairs, a serving table, provisions and shelving, with a clear central aisle to actual stairs and two guest beds upstairs. All14 furnishings use existing loaded models; no catalogue bulk or extra download. Saved older rooms retain their exact edits and contents; new defaults never regenerate them. Small/legacy templates keep their earlier furniture path. Standard rooms batch repeated stair treads/posts/rails by material and visibility parent: sampled inn calls73→42 downstairs/96→57 upstairs, town house70→28/106→43. Actual geometry/normals/UVs and cutaways are retained; buffers grow about55–69KB and some inn views submit up to6.3% extra triangles due to batch culling. This is a measured workload tradeoff, not physical FPS.

FOXGLADE: Fresh layout-8 valleys add a woodland ranger cottage, clearing, gardens and dry winding trail connecting Foresters’ Rest to the camp in the same connected world. The cottage has a separate furnished one-storey room with native save/reload and fade return to the same exterior. The real-geometry map now has ten destinations; tap the minimap, drag/pinch and tap a landmark or Home for safe travel. Existing layout-7 and earlier saved scenes/constructions keep their exact geometry; a new world does not reinterpret old records.
