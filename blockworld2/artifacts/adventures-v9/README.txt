BlockWorld Adventures — Development Preview 09

Unzip into a NEW folder. Run `python3 preview.py` (Windows: `py preview.py`).
Open http://localhost:8000/adventures.html . Direct file:// opening is unsupported because this app loads ES modules and GLBs.

This is an isolated LOCAL development preview. All models, images, animations and licences are included; no accounts, CDN downloads or purchases are needed. Nothing is deployed or published. Exact runtime source: https://github.com/novice-builder/object-builder/tree/57f4d0a30d9c2735893f831e00a2d5b8001ca978

Enter cottages, town houses, inns and smithies using the compact Enter prompt. The screen fades to a separate furnished 3D room; houses and inns have REAL WALKABLE STAIRS and a connected upper floor. Walk upstairs/downstairs normally using the same joystick, keyboard or browser-mapped gamepad. Each building retains its own furnishings and edits. Exit fades back to a clear position at the SAME building and restores outdoor facing. The original Meadow Lodge keeps its working physical door. Mills, church and market do not yet have separate rooms. Furnishings remain modest; beds, bedrooms, shop counters and building-specific activities are unfinished.

FIRST ENTRY into a version-1 saved world makes an independently named interior copy and KEEPS THE ORIGINAL RECORD. Room-enabled version-2 backups need Preview 09 or later; older previews reject them. Earlier scenery and independent Preview 01/02 records are not silently combined or remapped. Native export/import uses checksummed .bw2 backups; import creates a new record. Export before changing browser, address or device. Failed writes/stale-tab conflicts preserve in-memory work and pause saving; export or Save a new copy to recover. The native persistence database/schema remains unchanged.

The Willow Vale is one continuous 370x196-metre world joining Willowmere, Whispering Wood and Maker's Meadow, two river bridges, Brookside, the foresters' cottages and (in fresh layout 5) Alderwick market town. Walk the roads without switching world/save. Existing layouts/constructions remain unchanged. Places lists older records and can create a fresh valley with Alderwick. No construction-migration tool is claimed. Future different worlds will use genuinely different themes; this package prioritises the connected valley.

Tap the circular minimap or press M for the actual-geometry full world map. Drag/pinch or use zoom controls; tap a meaningful named destination for checked safe travel. Home returns to Willowmere. Indoors, the map locates the exterior entrance; explicit map travel safely leaves the room for the selected destination. The full map pauses hidden 3D rendering. Fades release held inputs and refuse rapid duplicate entry. Reload restores a complete location, including an upper floor. Fully blocked exits refuse unsafe travel; the map offers other safe destinations.

WASD/arrows walk; Shift runs; drag to orbit; wheel/pinch zooms; E interacts; B opens Build; Escape closes overlays. Touch uses a left joystick, another thumb to look and a Run toggle. Standard browser Gamepad API controls: left stick walks, right stick looks, A confirms/interacts/places, B goes back, X Build, Y interact, RB rotate, LS click Run, View map, Menu. D-pad navigates menus; mapping help is in the menu. Release controls after opening overlays/reconnecting. Touch and keyboard remain available if the Gamepad API is denied/unavailable. Physical Xbox/Bluetooth is UNVERIFIED; secure-origin/browser restrictions may apply.

Use Build to decorate rooms or create outdoors. Choose an existing model, tap nearby visible supported ground/floor, rotate and choose Place. Furniture snaps to quarter metres. Tap your own object to move, rotate or remove it; Undo/Redo are in the menu. Rooms reserve stairs/landings and exit space. New furniture remains on the selected floor; walk there before editing it. Outdoor paths, water, simplified collision, reach and save guards remain. No generic material catalogue expansion is included. New tents retain corrected human scale; explicit old saved scales stay unchanged. Supplied Explorer idle/walk/run animations and smooth turning remain; no dedicated turning clip is claimed.

Gentle graphics is the conservative fresh touch default; all explicit stored graphics/Run choices remain. Indoor rendering suspends the cached outdoor group and reuses the same licensed model library and renderer. Repeated-room resource checks plateau in the measured route. Tree camera-only crowns use actual indexed leaf bounds while walking still uses trunks. Close-camera actor hiding and responsive interior framing keep routes visible. No software-rendered FPS is represented as physical-device performance.

For phone/tablet on the same Wi-Fi: `python3 preview.py --lan`, then open http://YOUR-COMPUTER-LAN-IP:8000/adventures.html . Plain LAN HTTP may restrict some browser APIs; UUID and selectable backup-text fallbacks are provided. Physical Lenovo, iPhone, Safari and controller testing remains UNVERIFIED.
